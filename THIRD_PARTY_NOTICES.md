## Optional model

The coarse model is downloaded only when requested. It is not included in the
source or default executable. The pinned public model repository declares MIT:
https://huggingface.co/xandergos/terrain-diffusion-30m-onnx/tree/ad2df557eca5645f588766101cf3bc3682455c3e

SHA-256: d6ca15b21b2e35d5e594a9ac7a4249a2376590c0ad2b5b49a1e6e2d033450008.

Worldcraft's regional hybrid uses the actual coarse model with custom conditioning.
It does not reproduce the full learned base/decoder cascade or the upstream
WorldClim synthetic-map factory. A saved hybrid world contains generated samples
and model identity; reopening it requires no model or network.

commercial engine assets or video frames are distributed.
